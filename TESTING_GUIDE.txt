📋 METHOD 5: BATCH TESTING ON MULTIPLE IMAGES
═══════════════════════════════════════════════

Create a test directory:
  mkdir test_images
  # Copy your foggy images here

Then run:
  source venv/Scripts/activate
  python -c "
import os
import cv2
import torch
from models.msffa_yolo import MSFFA_YOLO

model = MSFFA_YOLO(num_classes=8).eval()

for img_file in os.listdir('test_images'):
    img = cv2.imread(f'test_images/{img_file}')
    img_tensor = torch.from_numpy(img).permute(2,0,1).float()/255.0
    with torch.no_grad():
        _, restored = model(img_tensor.unsqueeze(0))
    result = (restored[0].permute(1,2,0).numpy() * 255).astype('uint8')
    cv2.imwrite(f'results/{img_file}', result)
    print(f'Processed: {img_file}')
"

Output: results/ folder with all processed images
